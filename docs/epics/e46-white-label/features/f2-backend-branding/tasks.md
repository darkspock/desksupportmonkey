## Detailed Tasks

### Phase 1: Configuration

#### Task 1: Add BRAND_NAME to backend config
- **Files:** `core/config.py`
- **What:** Add a `BRAND_NAME` setting to the Pydantic `Settings` class with default `"DeskSupportMonkey"`. Update `SMTP_FROM_NAME` default to reference `BRAND_NAME`. This way, setting `BRAND_NAME=MyBrand` in `.env` propagates to all email sender names automatically.
  ```python
  BRAND_NAME: str = "DeskSupportMonkey"
  SMTP_FROM_NAME: str = ""  # defaults to BRAND_NAME if empty
  ```
- **Deps:** None
- **Acceptance:** `settings.BRAND_NAME` returns configured value; `SMTP_FROM_NAME` falls back to `BRAND_NAME` if not explicitly set
- [x] Done

### Phase 2: Email Templates

#### Task 2: Replace hardcoded brand in email templates
- **Files:** `core/email.py`
- **What:** Replace all hardcoded "DeskSupportMonkey" in email HTML and subject lines with `settings.BRAND_NAME`:
  - Line ~75: `<h2>Sign in to DeskSupportMonkey</h2>` → `<h2>Sign in to {settings.BRAND_NAME}</h2>`
  - Line ~89: Subject `"Sign in to DeskSupportMonkey"` → `f"Sign in to {settings.BRAND_NAME}"`
  - Line ~111: Subject `"New admin promoted - DeskSupportMonkey"` → `f"New admin promoted - {settings.BRAND_NAME}"`
- **Deps:** Task 1
- **Acceptance:** Emails sent by the system show the configured brand name in subject and body
- [x] Done

### Phase 3: PDF Report Templates

#### Task 3: Replace hardcoded brand in PDF report templates

- **What:** Replace hardcoded "DeskSupportMonkey" with a Jinja2 variable `{{ brand_name }}`:

  - `base.html` line ~101: `Generated by {{ brand_name }} — {{ generated_at }}`
  - `compliance_report.html` line ~111: `{{ brand_name }} — Compliance Posture Report`

  Also update the report generation code (Celery task or report service) to pass `brand_name=settings.BRAND_NAME` to the Jinja2 template context.
- **Deps:** Task 1
- **Acceptance:** Generated PDF reports show the configured brand name in headers and footers
