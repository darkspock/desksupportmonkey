## Phase 4: Celery Task Implementation

### Task 4.1: Implement generate_report task
**File:** `core/tasks/reports.py` (UPDATE from F0 skeleton)
- Full implementation:
  1. Load report record
  2. Update status to processing
  3. Call data collector based on report type
  4. Render Jinja2 template with data
  5. Convert HTML to PDF with WeasyPrint
  6. Upload PDF to S3
  7. Update report status to completed with storage_key
- Error handling:
  - On exception: update status to failed, set error_message
  - Retry with exponential backoff (Celery self.retry)
  - After max retries: leave as failed
