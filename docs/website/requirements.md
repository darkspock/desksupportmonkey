# DeskSupportMonkey Website — Requirements

## Overview

Marketing and documentation website for DeskSupportMonkey, built with **Astro**. The site serves as the public face of the project: showcasing the product, its open-source nature, the AI-driven development story, and training resources.

**URL structure:** Served from `web/site/` (Astro project).

---

## Key Messages

1. **100% AI-Built** — Every line of code was generated by AI (Claude Code), guided by a human architect using Spec-Driven Development.
2. **Open Source** — Full source code available on GitHub.
3. **Real-World DDD + CQRS** — A production-grade reference implementation, not a toy demo.
4. **Learning Resource** — Companion to two published books and an AI development course.

## Design Guidelines

- **Style:** Clean, modern, developer-oriented (similar to Astro's own site or Tailwind's site)
- **Colors:** Slate/blue palette consistent with the app (slate-900 for dark sections, blue-600 for CTAs)
- **Typography:** System font stack or Inter
- **Responsive:** Mobile-first, works on all screen sizes
- **Dark sections:** Use dark backgrounds (slate-900) for hero and featured sections
- **Light sections:** White/slate-50 for content sections
- **Code blocks:** If showing architecture or examples, use syntax-highlighted code blocks

---

## Technical Requirements

- **Framework:** Astro (static site generation)
- **Styling:** Tailwind CSS
- **Deployment:** Static files, can be hosted on GitHub Pages, Vercel, or Netlify
- **No JavaScript required** for content pages (Astro islands only where needed)
- **SEO:** Meta tags, Open Graph, structured data
- **Performance:** Lighthouse score > 95 on all metrics
- **i18n:** English only for now (Spanish can be added later)
