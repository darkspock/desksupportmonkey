# Senior Full-Stack Engineer

## Role Summary

The third hire. Joins when the CTO needs to multiply their output. This person is a strong individual contributor who can own features end-to-end — from database migration to React component — without hand-holding. They also pick up DevOps and infrastructure tasks as needed.

---

## Responsibilities

### Backend Development
- Implement new features following DDD + CQRS patterns established by the CTO
- Write and maintain Alembic migrations
- Build and maintain API endpoints (FastAPI)
- Write unit and integration tests to the project standard

### Frontend Development
- Build React pages and components (TypeScript, Tailwind CSS)
- Maintain i18n strings (EN + ES)
- Collaborate with the CTO on UI architecture and component design

### Infrastructure & DevOps
- Manage staging environment deployments
- Respond to non-critical incidents and monitor logs
- Assist with CI/CD pipeline maintenance

### Code Quality
- Participate in code reviews
- Run linters (mypy, flake8) and fix type errors
- Maintain test coverage above agreed threshold

---

## Skills Required

- Python (FastAPI, SQLAlchemy, Celery) — strong
- TypeScript + React — strong
- PostgreSQL — intermediate
- Git, Linux, basic DevOps — intermediate
- Ability to read and follow architectural patterns (does not need to invent them)
- Self-directed: can take a tasks.md file and execute independently

---

## Metrics Owned

- Feature throughput (tasks completed per sprint)
- Test coverage contribution
- Bug rate of own code in production

---

## Ideal Background

3-5 years of full-stack experience in a product team. Has worked in a Python + React stack. Comfortable with terminal and deployment workflows. Does not need a UI designer to ship good-looking interfaces.
